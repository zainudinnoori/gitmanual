# Code of Conduct

gitmanual follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers (helping them is the whole point of this project), and keep criticism about code, not people. Harassment, insults and discrimination aren't tolerated in issues, pull requests, discussions or anywhere else the project is represented.

To report unacceptable behavior, use **Security → Report a vulnerability** on this repository (it reaches the maintainers privately) or contact a maintainer directly. Reports are handled confidentially. Maintainers may remove comments, commits and contributions that break these rules, and may block repeat offenders.
